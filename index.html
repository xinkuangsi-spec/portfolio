CrossCast跨境电商短视频多 Agent 平台

跨境卖家做海外营销，选题靠猜、内容产出慢、各国广告规则不熟容易被罚。CrossCast 让一个人指挥一支 AI 团队：4 个流水线 Agent 接力完成爆款分析、内容与分镜、合规审查和发布排期，另有出片总控、实拍剪辑 2 个独立 Agent 负责视频。人工复核后发布，已在 TikTok、YouTube 真实发布。

系统里的几条硬约束

  • Agent 之间传产物，不让模型复述 ID；任一棒没产出、风控没调合规检查、判定拦截，链条当场断掉

  • 工具权限在执行层按白名单校验，不寄望于提示词

Qwen3.5-2B 三值量化个人研究

把 Qwen3.5-2B 的文本权重压成 {−1, 0, +1} 三值，合 2.16 bit/权重，在云 GPU 上做量化感知训练（QAT）和知识蒸馏。

  • 8 项评测平均保留 FP16 的 61.2%（直接比例），PIQA 85.4%
  • 查出学习率是训练早期崩溃的主因；之后先换随机种子量出噪声范围，再做 6 组单变量对照
  • 补解题过程数据，按 13-gram 剔除和 GSM8K 测试集重合的 661 条，GSM8K 从 0.8% 升到 7.3%

qlink两台电脑的 Agent 协作通道

团队日常协作用的通道：两台电脑上的编程 Agent 按「项目 + 任务线程」协作，发消息、认领任务、在对方认领的项目文件夹里跑命令、传文件。

  • 两端都只主动外连中转，零入站端口；每台机器一把令牌，TLS 固定证书防中间人
  • 远程执行可以关掉，所有命令写审计日志；单文件最大 2 GB，中转保留 7 天
  • 以 MCP 接进各家 Agent；黑客松决赛前，我们俩来回改的路演稿就走这条通道

05 · 做法

两台电脑，一个大脑

  1. 01按线程分工

    每个任务开一个线程，对方认领后才在他的项目文件夹里执行；消息、命令、文件都走 qlink，全程留审计日志。

  2. 02共享大脑

    两个人踩过的坑写进同一个知识库，开工前先查对方的经验，同一个坑不交两次学费。

  3. 03先探边界

    动工前先实测，不凭文档猜。企业微信项目开工前，两天内封死六条「不备案也能接」的绕行方案。

  4. 04真跑验收

    交付前按真实路径跑一遍、逐项对照验收；改动单独做对照，先量噪声再下结论。
